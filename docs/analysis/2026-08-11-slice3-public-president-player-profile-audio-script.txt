Do not simply delete old President pages. Keep slash presidents slash id as compatibility. If a legacy President row maps safely to a Player by user id, redirect to that Player profile. If not, show a deprecated compatibility state.

Admin President tools must stay intact. Legacy President transfer and history tools are admin compatibility, not public identity.

Out of scope: Transfer Room, feed and media cleanup, contract lifecycle changes, STC economy, and trophies.
